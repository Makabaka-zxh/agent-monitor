# Windows 桌面小组件

安装项目已有依赖后，双击 `start-desktop.cmd` 打开原生窗口。需要带 Tk 的 Python（Windows 官方安装包默认包含）；不增加重型桌面框架。启动器使用 `pythonw`，不常驻命令行窗口，也不自动安装依赖。

## 扫码配对

点击「扫码配对」，输入手机可访问的 HTTPS 服务地址和电脑别名。手机扫码，在已登录的 Monitor 确认页核对电脑后点连接。二维码十分钟有效；失败或到期后不会自动生成新的请求。关闭配对窗口取消本机等待。

二维码、复制按钮和打开按钮只使用服务验证地址，不包含领取密钥或连接令牌。令牌仅按现有连接器格式保存在本机受保护的配置文件中；任何已存在的配置都不会被覆盖。扫码完成不代替手机确认，也不绕过服务鉴权。

本组件不自动启动第二个采集器，不上传任务正文，不改变既有连接器的同步或回复权限。已有连接器继续运行即可；新电脑配对后仍需按连接器说明启用同步。

## 用量与小窗

默认读取连接器状态目录里的现有 `usage.sqlite3`，只读、不建库、不迁移、不扫描日志。每十五秒更新一次。账号额度按实际可用窗口显示；缺失或已过期的窗口隐藏，真实 0% 保留，未过期旧观测标注「上次观测」。不同模型或额度桶分别展示，不把模型桶当总额度。

模型构成显示本机当天已记录 Token 的比例，分母包括缓存 Token 和未识别模型；它不是账号额度百分比，也不是账号所有设备的完整用量。没有已识别模型数据时隐藏构成区，不填假零。所有日期以账本 `Asia/Shanghai` 的当天为准。

「切换小窗」保留简洁的 Token 与窗口额度；「展开详情」显示模型构成。「置顶」可随时关闭，不改变系统其他窗口。没有任何数值时只显示整体空状态。

可明确选择已有状态目录或本机匿名账本：

```powershell
start-desktop.cmd --state-dir "C:\Monitor\.state\agent" --usage-db "C:\Monitor\.state\usage.sqlite3"
```

不应把别的账号或陌生文件当作用量库。目录不跟随符号链接或重解析点。旧数据库格式不兼容时显示空状态，不自动修改旧库。

## 离线演示

```powershell
start-desktop.cmd --demo
```

演示窗口明确标注「演示数据」，使用固定合成 Codex / Claude 数据，不读真实配置、账本或日志，不联网，不生成配对请求。可切换小窗和置顶检查布局。演示不代表真实账号额度或实机验收通过。
