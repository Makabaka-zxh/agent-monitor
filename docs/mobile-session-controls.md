# 手机、Windows 与 macOS 提问、批准与模型选择

原生 Android、Windows 与 macOS 客户端的任务详情可以显示已连接会话发出的提问和操作批准请求。选项、操作内容、可用模型和思考强度来自对应电脑上的工具，不根据任务文字推测。

## 可用范围

- Monitor 发起的续接会话支持实时交互。本机 Claude Code 还可以在启动时指定一台已配对的手机，让电脑发起的选择题出现在这台手机上。[Claude 桌面选择题接入](claude-desktop-questions.md)
- 仅采集日志的电脑会话仍需在来源电脑处理原始请求。接入前已经弹出的选择题无法从日志补答。
- Codex 支持已绑定当前会话、轮次和请求的提问，以及能够完整展示范围的单次命令或文件修改批准。额外网络、权限范围或长期规则调整不转换成普通批准。
- Claude 支持兼容版本双向通道中的提问和单次工具批准。保持原会话可验证的权限模式；不把思考强度当作权限模式，也不自动扩大权限。
- Antigravity 在电脑端安装并登录官方 `agy` CLI 时，支持通过 `agy acp` 续接未被桌面端占用的已空闲工作区会话，提供模型与思考强度目录拉取、表单式结构化提问回答及单次批准／拒绝；不开放永久允许（`allow_always`）、外部链接类质询或跳过权限开关。
- 当前版本或连接方式无法提供可靠能力信息时，相应按钮不出现，或者显示不能处理的原因。

## 提问和批准

Codex 在已连接的轮次里发出异步选择题时，手机会显示原题和选项，也可以自行填写。答案按题号送回同一轮，Codex 接收后显示「电脑已收到」。异步提问期间 Codex 可以继续工作，原轮次结束时手机答题入口随之关闭。

Android、Windows 与 macOS 工作台会把当前客户端可回答的任务标为「等待回答」，单次操作确认标为「等待批准」。点开任务，在详情靠前的「待你处理」中阅读工具给出的题目和选项，选择后点「发送回答」。一条请求包含多道题时需要逐题填写。桌面工具只报告等待状态、尚未提供可回答的请求时，工作台显示「待处理」。

Codex 支持原生选择题，以及绑定当前轮次的 MCP 枚举表单。Claude Code 的 `AskUserQuestion` 支持单选和多选，带预览的题目也会显示选项文字和说明，预览可在电脑上查看。Antigravity 支持有显示标签和直接使用枚举值作选项的表单，手机把选择映射回表单要求的原值。

问题不默认提交答案。可选择问题提供的选项；允许自定义文字时，自定义回答替代列表选项。客户端会先展示完整操作，批准只针对该次请求，也可以拒绝。

电脑端 Codex 支持时，可以在回复设置里为下一条回复选择计划模式。计划模式允许 Codex 在需要时发出结构化问题，但不会保证每次都提问。普通回复不会沿用这次计划模式，原有权限和审批规则保持不变。

“已发送”表示 Monitor 已收到决定；“已交给电脑”只表示决定已写入电脑端通道，不代表代理已经接受或操作执行成功。执行结果以任务结果为准。请求取消、过期、内容变化或服务重启后，不再允许沿用旧决定执行。网络重试沿用原提交编号和原决定，不生成第二次批准。

## 模型与思考强度

只显示当前工具返回的可用模型及其支持的思考强度。缺少模型目录或对应字段时隐藏该项。

设置从下次发送时应用，不修改正在执行的任务或全局配置。工具可能在此会话后续继续沿用这些设置；这里不承诺单轮结束后自动恢复。“继承电脑设置”不发送额外模型参数。目录过期或选择失效时，需要刷新重选。已发送或重试中的回复保留原文本和原设置，避免重复发送时偷偷切换模型。

## 错误原因

启用原有结果同步后，可以显示本轮工具明确报告的固定错误类别，或本轮最终回复中可识别的报错信息。额度耗尽、普通限流、登录失败、计费异常、服务繁忙、连接中断等分别展示。

服务错误类别不是独立根因诊断。没有可靠位置时不显示文件或行号，不从 HTTP 429 推断额度耗尽，也不自动充值、开启额外用量或反复重试。关闭结果同步后，错误分析和固定错误类别一并清除。

## 验证边界

开发验证使用隔离的合成会话、请求和目录，不执行真实批准或付费代理轮次。离线测试不能替代原生客户端显示、真实工具兼容性和真实批准链路的实机验收。
