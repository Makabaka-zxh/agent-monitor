# 连接电脑与同步权限

在拥有目标会话记录的用户账号下安装 Python 依赖。每台电脑需要单独配对，不能复制其他设备的凭据文件。

```sh
python -m agent_monitor.remote_agent pair-qr --server https://monitor.example.com --name "开发电脑"
python -m agent_monitor.remote_agent run --status-only
```

配对二维码需要在已登录的 Monitor 中确认，也可使用工作台生成的一次性配对码：

```sh
python -m agent_monitor.remote_agent pair --server https://monitor.example.com --code YOUR_PAIR_CODE --name "开发电脑"
```

`--status-only` 只同步状态，不上传结果或附件，也不接收回复。验证状态正常后，在设备同步设置中明确启用需要的结果、文件与回复能力，然后按需要去掉此参数。可用 `run --once --status-only` 做一次状态检查。不同命令的 `--state-dir` 必须保持一致；配置和凭据保存在私有状态目录内。

## 数据来源与限制

- 采集当前用户有权读取的 Codex / Claude Code / Antigravity 会话文件与生命周期信息。不同 CLI 版本、hook 配置或后台子任务会影响状态准确性。
- 最终结果不包含完整思考链；下载限于工具明确关联且通过路径和大小校验的文件，并非任意远程文件浏览器。
- 同会话回复需要对应工具可用且已登录，并由该设备显式启用。不要以管理员或 root 身份运行连接器。
- Token 与套餐窗口只展示可读取的数据，来源缺失时显示未知。它们不是供应商账单。
- 断网会使状态滞后，过期信息不应视为任务完成证据。

### Antigravity 桌面会话

新版连接器自动查找当前系统用户的 `~/.gemini/antigravity` 会话索引。索引可读时，桌面主会话会以「Antigravity」为来源出现在工作台，可按工具和电脑筛选。超过状态有效期的运行会话、正在取消或尚未完全空闲的会话，不能以这份数据认定为已完成。当前在 Windows 桌面版 2.32.1 上核对了真实会话；索引缺失或格式不兼容时会跳过这个来源。

开启结果同步后，Monitor 只读取能与最新一轮确认对应的最终答复文本及已校验的配套交付文件（包括本轮在工作区内生成并显式引用的文件、会话 `brain/<id>/` 顶层显式引用文件，以及本轮标记为 `userFacing: true` 的顶层报告产物，排除 `.system_generated`、`scratch`、`browser_sandbox` 与 `.metadata.json`）。远程连接器每次检查最近 8 条已空闲的 Antigravity 会话；本机服务可在打开详情时读取其他已收录会话的结果与附件。关闭结果同步或使用 `--status-only` 时不读取正文与文件。用量账本还会按只读增量方式统计 `brain/<id>/.system_generated/logs/transcript.jsonl` 中已完成步骤的本地 Token 与公开模型占比（本地日志不含官方套餐滚动额度窗口）。当所在电脑已安装并登录官方 `agy` CLI（`v1.5+`）且显式启用回复能力时，Monitor 可通过 `agy acp` 续接已空闲且未被桌面窗口或 CLI 占用的本地工作区会话，在原生 Android 与 macOS 客户端支持模型与思考强度选择、表单式提问回答（`elicitation/create`）以及单次命令或工具批准（`session/request_permission`）；桌面窗口正在占用同一会话、缺少安全工作区或处于自动扩权模式时拒绝续接并提示回电脑处理。

需要同时更新 Monitor 服务和电脑连接器。连接器遇到仍不识别 Antigravity 的旧服务时，照常同步已有的 Codex 和 Claude Code 任务。

### Codex 压缩日志（源码新增，尚未发布）

任务采集支持 `sessions` 下的 `.jsonl` 和 `.jsonl.zst`。同目录同名文件同时存在时优先普通 `.jsonl`，两份只占一个候选名额；压缩前后的任务身份一致，不同文件中的相同会话 ID 仍合并成一项。需安装更新后的 Python 依赖，其中包含固定版本的 `zstandard`。

范围仍为每个工具最近 50 个候选文件，按修改时间排序；子代理仍占候选名额但不显示，也不从更早文件补齐。两种工具合并后最多 50 项。本次没有加入归档目录、数据库回填或全历史搜索，范围之外的旧主任务不会因支持压缩格式而自动补录。

常规状态解析仍只使用 256 KiB 的完整行头尾窗口。近期日志状态无法确定时，可扩大到 1 MiB。压缩流逐块处理，单文件最多读取 128 MiB、解码 1 GiB，解码器窗口保持 8 MiB、单块最多 128 KiB。每轮压缩读取另受 512 MiB 输入、2 GiB 解码工作量和 8 秒预算约束，单文件为 4 秒；时间在受限读取、解码前后检查，不能强行中断阻塞中的底层 I/O。

已完整校验且文件身份、大小、时间及祖先目录身份未变化的有限头尾数据可复用内存缓存，缓存总量最多 16 MiB、最多 64 项；任务状态与过期时间仍每轮重新计算。不会把解压后的日志写回磁盘，也不会缓存未验证的尾部。损坏、截断或超限会显示读取不完整；若已读到可识别的主任务元数据，保留该任务并把状态设为未知，不展示未验证尾部的完成状态或结果。整轮预算先耗尽时，尚未处理的候选可另读元数据前缀，单份前缀读取和解码各最多 256 KiB、时间预算 0.25 秒；仍缺少可识别元数据的文件无法安全收录，会计入读取不完整的提示。上述预算不改变最近 50 个候选、子代理排除及不回填规则。

这项格式支持覆盖任务采集和已授权的最终结果读取，不扩展用量账本的独立扫描规则。验证使用合成日志，不代表已部署到正在运行的连接器。

macOS 原生客户端及用户级连接器的构建与地址配置见 [构建说明](BUILDING.md)。本版本提供源码，不提供经过 Apple 公证的安装包。Windows 自动启动脚本只面向已登录用户，不保存系统密码。

## 撤销

从自己的 Monitor 设备管理页撤销不再使用的设备，并停止该电脑的连接器。删除本地配置不等于服务端已经撤销凭据；优先在线完成撤销。不要将 `.state`、钥匙串导出、Codex 或 Claude Code 登录文件上传到 GitHub。
